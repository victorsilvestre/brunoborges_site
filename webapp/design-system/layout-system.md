# Layout System

## Grid and Containers
- **Container Principal**: Largura máxima contida (ex: 1200px) centralizada para manter a legibilidade densa.
- **Columns**: Padrão de 12 colunas css-grid para flexibilidade. Banners promocionais devem romper o grid e ir de ponta a ponta (full-bleed) para impacto fotográfico.

## Seções (Sections)
- **Hero Sections**: Sempre em tela cheia (100vh) ou quase isso. Fundo com foto borrada do mercado, alinhamento de texto à esquerda (ou central caso a promessa seja singular).
- **Features/Benefits**: Múltiplos cards dispostos em grid (3 ou 4 por linha). Carga visual alta, simulando interface técnica.

## Organização de Conteúdo
- Tipografia escalonada duramente. Títulos pesados e curtos. Textos de apoio compactos e diretos, alinhados à esquerda para leitura rápida.
- Padrões de Z-index: Modais e Banners "Flutuantes" devem ficar sempre à frente, sem overlays brancos (o overlay deve ser um multiply/escuro quase total).
